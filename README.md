# Páginas de información — materiales profesionales

Sitio independiente para presentar los materiales digitales y dirigir a las páginas de compra de Hotmart.

## Alcance

- Contenido comercial y educativo de carácter general.
- Muestras visuales y ejemplos descriptivos, sin entregar los archivos completos.
- Enlaces de compra exclusivamente hacia Hotmart.
- Sin conexión con el sistema de gestión ni con las bibliotecas públicas de materiales.

## Publicación

Este proyecto está pensado para publicarse como un repositorio independiente en GitHub Pages.

Páginas:

- `index.html` — portada.
- `kit-terapia-lenguaje.html` — Kit de Terapia del Lenguaje.
- `kit-intervencion.html` — Kit de Intervención.

Antes de publicar, revisar los textos, la identidad visual y los enlaces de Hotmart. Las muestras son demostrativas y no sustituyen la descripción ni las condiciones de compra de Hotmart.
