Secuencia para comunicar

Comprensión · expresión · turnos

Observar, elegir y expresar

Una actividad para construir un mensaje a partir de una escena, una elección visual y una frase funcional.

Cómo se realiza
  1. Presenta una imagen de una situación cotidiana y deja unos segundos para observar.
  2. Pide identificar quién aparece, qué está haciendo y qué podría ocurrir después.
  3. Ofrece dos o tres opciones visuales para elegir la acción o la respuesta.
  4. Modela una frase breve y luego invita a producirla con el nivel de ayuda necesario.
  5. Amplía el mensaje con una pregunta: “¿dónde?”, “¿cuándo?” o “¿por qué?”.
Ejemplo orientativoEscena: una persona prepara una merienda. Respuesta inicial: “come”. Expansión: “La niña come una manzana en la mesa”. Seguimiento: elegir entre “tiene hambre” y “tiene sueño” y explicar qué pista de la imagen ayudó.

Se puede responder señalando, con palabras, gestos, pictogramas o un dispositivo de comunicación.

Práctica de un sonido

Habla · articulación · generalización

Escuchar, producir y usar

Una secuencia graduable para trabajar un sonido objetivo previamente definido por el profesional.

Cómo se realiza
  1. Selecciona el sonido objetivo y verifica que la persona comprenda la consigna.
  2. Comienza con discriminación auditiva: escuchar dos palabras y señalar si suenan igual o diferente.
  3. Practica el sonido de forma aislada o en sílabas, sin forzar repeticiones.
  4. Pasa a palabras y frases cortas con apoyo visual y retroalimentación concreta.
  5. Cierra con una situación comunicativa: pedir, describir o responder usando algunas palabras objetivo.
Ejemplo orientativoSonido objetivo: el que corresponda a la evaluación. Paso 1: escuchar dos opciones. Paso 2: repetir una sílaba. Paso 3: nombrar tres imágenes. Paso 4: usar una palabra en una frase. Registro: tipo de ayuda, precisión aproximada y comodidad durante la tarea.

La selección del sonido, la meta y el criterio de avance corresponden al profesional responsable.

Seguir instrucciones y pedir ayuda

Comprensión · vocabulario · autonomía

Escuchar, ejecutar y revisar

Una actividad funcional para practicar instrucciones de uno o dos pasos en un contexto significativo.

Cómo se realiza
  1. Elige objetos conocidos y define una acción observable, como buscar, entregar, poner o guardar.
  2. Da una instrucción breve y espera antes de repetirla o añadir apoyo.
  3. Observa si la persona comprende el vocabulario, la secuencia y la relación espacial.
  4. Si hay dificultad, ofrece una pista visual o divide la consigna en pasos más pequeños.
  5. Enseña una frase para pedir repetición o ayuda y registra qué apoyo permitió continuar.
Ejemplo orientativoConsigna: “Busca el lápiz y ponlo dentro de la caja”. Primero se muestran los objetos; después se retira la ayuda visual. Si se detiene, puede usar “repítelo” o “ayúdame”. Registro: completó el primer paso solo y necesitó una señal para ubicar la caja.

La actividad puede trasladarse a rutinas de aula, casa o consulta, ajustando vocabulario y complejidad.
