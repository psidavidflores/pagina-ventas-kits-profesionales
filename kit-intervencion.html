Clasificar y atender

Atención · seguimiento de reglas

Buscar, comparar y responder

Una actividad graduable para practicar atención sostenida, discriminación visual y respuesta a una consigna.

Cómo se realiza
  1. Presenta una hoja con símbolos o imágenes y define una regla simple: marcar solo los elementos que cumplen el criterio.
  2. Haz un ejemplo guiado y pide que la persona explique qué debe buscar.
  3. Trabaja durante dos minutos sin cambiar la consigna.
  4. Revisa aciertos, omisiones y respuestas impulsivas sin convertir el resultado en una calificación.
  5. Repite con una variación: más elementos, doble criterio o menor ayuda.
Ejemplo orientativoConsigna: “Rodea los animales y tacha los objetos”. Primero se resuelven tres elementos juntos; después la persona continúa sola durante un minuto. Registro: encontró 8 de 10 animales, confundió dos objetos y necesitó una repetición de la regla.

Se adapta modificando cantidad, tiempo, complejidad, apoyo visual y forma de respuesta.

Semáforo para autorregularse

Emoción · pausa · elección

Identificar, detenerse y elegir

Un apoyo visual para practicar qué hacer cuando una emoción intensa dificulta continuar una actividad.

Cómo se realiza
  1. Presenta tres zonas: rojo para “necesito parar”, amarillo para “puedo pedir ayuda” y verde para “puedo continuar”.
  2. Lee una situación cotidiana y pide identificar la señal corporal o emocional.
  3. Elige una acción de pausa segura: respirar, contar, tomar agua, cambiar de espacio o pedir apoyo.
  4. Ensaya la respuesta con una frase funcional: “Necesito una pausa” o “Explícame otra vez”.
  5. Practica una segunda situación y conversa sobre cuándo transferirlo a la vida diaria.
Ejemplo orientativoSituación: una actividad no sale como esperaba. Rojo: aprieto las manos y quiero abandonar. Amarillo: paro, miro la tarjeta y pido una pista. Verde: pruebo una estrategia más y reviso si necesito cambiar la tarea.

La persona no tiene que memorizar el código; el profesional puede usar colores, palabras, gestos o pictogramas.

Plan de actividad funcional

Planificación · autonomía · seguimiento

Convertir un objetivo en una sesión

Una plantilla para organizar una actividad desde el inicio hasta el registro final y el próximo ajuste.

Cómo se realiza
  1. Define un objetivo observable: por ejemplo, completar una rutina con menos apoyos.
  2. Prepara materiales, lugar, tiempo estimado y una instrucción breve.
  3. Divide la tarea en pasos y decide qué ayuda ofrecer solo si es necesario.
  4. Registra qué hizo de forma independiente, qué apoyo necesitó y qué parte fue difícil.
  5. Elige un ajuste para la siguiente práctica: menos ayuda, más tiempo o un paso intermedio.
Ejemplo orientativoObjetivo: preparar una mochila con cuatro elementos. Pasos: revisar lista, buscar materiales, guardarlos y comprobar. Registro: completó los tres primeros con una señal visual; necesitó ayuda para revisar. Próximo ajuste: mantener la lista y retirar una indicación verbal.

La meta, los apoyos y el criterio de avance se definen según la evaluación y el contexto.
